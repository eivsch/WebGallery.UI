# Project goals

## Purpose

WebGallery is a hobby project for personal media: a personal “YouTube + images” for organizing and browsing media. It is not intended for production or public use.

## Current experience

The app supports browsing albums, searching media, viewing watch history, and retrieving albums or media at random.

## Possible future directions

A recommendation feature and backend AI for analyzing or classifying images and videos are possible directions, not commitments.

## Engineering priorities

- Favor simple designs that are easy to maintain. Avoid extra layers or complexity without a clear benefit.
- Keep testing needs modest: manual checks are the main approach, and a large test suite is not a goal.
- Authentication and security are lower priorities for this personal-use hobby project.
- Performance is the exception: added complexity can be worthwhile when it provides a tangible performance benefit.
